 Iris Dataset – Data Preparation

This project focuses on cleaning and preparing the Iris flower dataset using Python and Pandas. The dataset contains measurements of three different iris species.

 this is what I did
- Checked for missing values and inconsistencies.
- Converted measurement columns to numeric types.
- Cleaned and standardized species names.
- Handled missing values using the median.
- Saved the cleaned dataset as a CSV file.

Tools Used
- Python
- Pandas
- Jupyter Notebook

 Dataset
Source: [UCI Machine Learning Repository – Iris](https://archive.ics.uci.edu/dataset/53/iris)

 I added a few sample data issues to a copy of the original dataset to practise data cleaning.
